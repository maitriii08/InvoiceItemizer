# InvoiceItemizer 🧾

> **Privacy-First, Local AI Invoicing for Freelancers**

InvoiceItemizer is a lightweight, zero-cost micro-SaaS web utility built for freelancers and independent developers. It takes messy, unstructured client notes, rough work logs, or receipt lists and instantly structures them into professional, itemized invoices.

## 🚀 Key Features
* **Zero Server Data Leakage:** Powered by Google's open-weight **Gemma** model running entirely client-side via WebGPU and Transformers.js. Your financial data and client notes never leave your laptop.
* **Instant Ingestion:** Paste raw, unstructured text (e.g., *"fixed homepage bug 5 hrs @ $50/hr, bought server domain for $15"*), and watch it format instantly.
* **Zero Infrastructure Cost:** Static deployment via GitHub Pages means $0 operating costs with no API rate limits or subscription fees.
* **Built with GitHub Copilot:** Rapidly prototyped and refined using GitHub Copilot Chat for clean UI scaffolding and local logic.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
* **AI Runtime:** Hugging Face Transformers.js + WebGPU (Gemma local inference)
* **Hosting:** GitHub Pages
